## Design Principles

The KISS principle means "Keep It Simple." Code should be easy to read, understand, test, and change. This means using clear names, short comments, small functions, and simple steps. It also means avoiding unnecessary code and complicated designs when a straightforward solution works.

I learned and applied KISS by organising the Python files into topic folders and keeping each example focused on one main idea. In the assignment programs, I used separate classes and methods for tasks such as managing accounts, books, members, and requisitions. I added short comments to explain the purpose of important sections, tested the files after changes, and avoided adding features that were not needed.



These examples are for learning. Some files show early practice, so they may not all use the same style.
